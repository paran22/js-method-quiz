함수 vs 메서드

오늘 "메서드"라는 말이 많이 나옵니다. 둘의 차이가 뭘까요?

// (A) console.log('hello'); alert('안녕'); // (B) 'hello'.toUpperCase(); [1, 2, 3].push(4); document.querySelector('h1');

(A)는 함수 — 독립적으로 호출

(B)는 메서드 — 객체에 점(.)을 찍고 호출
